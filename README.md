# ZEN 禅 · Том первый — портфолио

Портфолио студии ZEN в серьёзном самурайском стиле: тёмная сцена, кроваво-красное солнце, горы тушью, сакура и катана, которая разрезает экран при прокрутке. Axioma — одна из работ студии. Все факты (цены, контакты, процесс, вопросы, принципы) совпадают с [axioma.codes](https://axioma.codes/) слово в слово: заявки и цены ведут туда же.

## Что внутри

- **Пролог.** Ронин на фоне красного солнца. На первой прокрутке клинок проходит по диагонали через все слои и заголовок, половины разлетаются, под ними открывается красная страница «Содержание».
- **Кодекс.** Три принципа Axioma (Разработка, Заметность, Внимание), их открывает горизонтальный разрез.
- **Работы.** 6 живых сайтов: Axioma, PLANET, NOIR DETAILING, Bloom Coffee, Lumen, Qala Build. Половину открывает разрез красно-чёрного «кровавого оттиска», половину — срезанная занавеска норэн. Потом сайт сам листается в окне браузера (при прокрутке и при наведении).
- **Цены.** «Три клинка и особый заказ»: лендинг, 3D-сайт, бизнес-сайт и сложный проект. Ленты-оби на карточках перерубаются.
- **Путь.** Четыре шага работы с огромными цифрами кистью и катаной, выходящей из ножен.
- **Вопросы, дуэль, контакты, титры.**
- RU и EN, спокойный режим (без анимаций, включается сам при `prefers-reduced-motion`), синтезированный звук (выключен по умолчанию), телефонная версия.

## Запуск

```bash
python -I tools/serve.py 5191
```

Открыть http://localhost:5191. Сборка не нужна: это статический сайт, подходит для GitHub Pages.

## Как менять

- Все тексты работ, цены, шаги, вопросы и принципы лежат в `js/data.js`. Русский текст попадает в `index.html` генератором, английский берётся из `js/data/en.js`. После правки запустите:

  ```bash
  node tools/build.mjs
  ```

  Генератор обновит блоки работ, цен, шагов, вопросов и кодекса, соберёт спрайт иллюстраций из `art/*.svg` и подберёт глифы шрифта Yuji Mai под кандзи на странице.
- Скриншоты работ лежат в `assets/shots/` (`{key}.webp`, `{key}-long.webp`, `{key}-m.webp`). Красные оттиски для разреза: `python -I tools/make-ink.py assets/shots`.
- Горы, круг энсо и мазок кисти генерируются: `python -I tools/gen-sumi.py`.
- Превью для мессенджеров: `assets/og.jpg`, шаблон `tools/og.html`.

## Устройство

| Файл | Что делает |
|---|---|
| `js/fx/slice.js` | Движок разреза: клонирует слои, режет их одной линией (или крестом) через статичный `clip-path`, рисует след клинка, делает стоп-кадр, проскальзывание и разлёт |
| `js/fx/fx.js` | Вспышка кандзи, печати, вспышка удара, тряска, брызги, звук |
| `js/fx/petals.js` | Лепестки сакуры на canvas |
| `js/scenes/*.js` | Сцены: пролог и кодекс, работы, цены/путь/вопросы/дуэль/контакты |
| `js/ui/ui.js` | Лоадер с катаной, шапка, меню, переключатели, курсор, индикатор, таймкод, шторка для телефона |

Библиотеки: GSAP 3.13 (ScrollTrigger, DrawSVG) и Lenis с jsDelivr. Если CDN недоступен, страница остаётся полностью читаемой без анимаций.
